# ASCII shark background

Adapted from [stackedlol/ascii-sharks](https://github.com/stackedlol/ascii-sharks), commit `c521e24a787e6d4cc460d4cf2b9815f25e4fe453`.

The local JavaScript modules retain the reference's shark silhouettes, articulated swimming and fish-school simulation. They add individual, capped growth and resize preservation, and replace the dark grid and coloured effects with transparent graphite rendering. `../recursive-field.js` connects the scene to the existing homepage with pause, reduced-motion and hidden-tab handling. No runtime dependencies or build step are required.
